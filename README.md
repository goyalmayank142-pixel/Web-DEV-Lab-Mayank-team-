# Student Profile Repository - Web Development Lab

A collaborative student profile repository built using Git and GitHub as part of the Web Development Lab activity at Bosscoder School of Technology.

---

## 🚀 Workflow Followed

1. **Repository Setup**: Initialized repository and established `main` branch with project documentation.
2. **Feature Branching**: Each team member worked in isolation on their respective feature branch (`feature/profile`, `feature/skills`, `feature/contact`).
3. **Staging & Commits**: Changes committed with clear, conventional messages.
4. **Pull Requests (PR)**: Raised PRs from feature branches to `main`.
5. **Code Review & Merge**: Team Lead reviewed and merged all approved PRs into `main`.
