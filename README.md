## 📚 Complete Lab Curriculum & Module Solutions

All exercises from Module 2 (HTML & CSS Foundations) and Module 3 (CSS Layout Systems) are implemented with complete semantic structures, responsive styles, and modern best practices:

### **Module 2: HTML & CSS Foundations (P5–P9)**
- **P5: Semantic bio page** &rarr; [`module-2/p5-semantic-bio.html`](module-2/p5-semantic-bio.html)
  - Uses `header`, `main`, `section`, `article`, `figure`, `figcaption`, and `footer`.
- **P6: Full portfolio page structure in semantic HTML** &rarr; [`module-2/p6-portfolio-structure.html`](module-2/p6-portfolio-structure.html)
  - Clean semantic landmark structure: nav bar, hero banner, about, skills, project cards, and contact sections.
- **P7: Design tokens and typography system in CSS** &rarr; [`module-2/p7-design-tokens.html`](module-2/p7-design-tokens.html)
  - CSS custom properties (`:root`) defining color tokens, typography scale, spacing units, and border-radii.
- **P8: Sticky navbar and card overlay using CSS positioning** &rarr; [`module-2/p8-sticky-overlay.html`](module-2/p8-sticky-overlay.html)
  - Sticky nav (`position: sticky; top: 0;`) and absolute gradient card overlay (`position: absolute`).
- **P9: Responsive navbar and card grid using Flexbox** &rarr; [`module-2/p9-flexbox-responsive.html`](module-2/p9-flexbox-responsive.html)
  - Dynamic wrapping navbar and multi-column card grid with mobile-first media queries.

### **Module 3: CSS Layout Systems (P10–P13)**
- **P10: Portfolio header and footer with advanced Flexbox** &rarr; [`module-3/p10-header-footer-flexbox.html`](module-3/p10-header-footer-flexbox.html)
  - Sticky footer architecture (`min-height: 100vh; flex: 1`) with grouped navigation and call-to-actions.
- **P11: Newspaper-style three-column layout with CSS Grid** &rarr; [`module-3/p11-newspaper-grid.html`](module-3/p11-newspaper-grid.html)
  - Classical editorial grid with proportional tracks (`2fr 1.2fr 1fr`), vertical separators, and responsive collapse.
- **P12: Portfolio projects grid with advanced CSS Grid** &rarr; [`module-3/p12-projects-advanced-grid.html`](module-3/p12-projects-advanced-grid.html)
  - Intrinsic responsive grid (`repeat(auto-fit, minmax(320px, 1fr))`) with flagship 2-column span cards.
- **P13: Choosing between Flexbox and Grid for a shared layout** &rarr; [`module-3/p13-flexbox-vs-grid-guide.html`](module-3/p13-flexbox-vs-grid-guide.html)
  - Comprehensive architectural guide and decision matrix: 1D vs 2D, Content-First vs Layout-First, and hybrid layout strategies.
